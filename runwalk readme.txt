# Walk vs Run Classification

## Project Overview
This project uses Machine Learning to classify human physical activity as Walking or Running using motion sensor data.

## Objective
To analyze accelerometer and gyroscope data and build a predictive model that identifies whether a person is walking or running.

## Dataset
The dataset contains sensor measurements including:
- Acceleration X, Y, Z
- Gyroscope X, Y, Z
- Wrist position
- Activity label

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras
- Google Colab / Jupyter Notebook

1. Data loading
2. Data cleaning
3. Exploratory Data Analysis
4. Feature selection
5. Data preprocessing
6. Machine Learning model training
7. Neural Network training
8. Model evaluation and comparison

## Models
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- Support Vector Machine
- Neural Network

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Conclusion
The project demonstrates how sensor data and Machine Learning can be used to recognize human physical activities such as walking and running.
